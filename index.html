How it works

  • A random 16-byte salt is generated for every account.
  • The password is processed with PBKDF2-HMAC-SHA-256 using 210,000 iterations.
  • Only the username, salt, hash, algorithm and iteration count are stored in localStorage.
  • The original password is never stored in localStorage.
